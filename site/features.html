feature map

Everything, already shipped.

No waitlist modules. The desktop shell, the full operational module map and the agent integrations are in the repo today.

Desktop shell

Movable windows

Draggable, resizable, minimizable windows with z-order and layout that survive reloads — plus a dock and module rail.

Command palette

Ctrl/Cmd+K opens everything: modules, records, full-text search results and actions, keyboard-first.

Multi-workspace

Organizations and workspaces with owner/admin/member/agent/viewer roles — switch from the top bar.

Graphite & Ember design

Dark and light themes on a real design-token system: Fraunces display, Instrument Sans, JetBrains Mono.

Operational modules

CRM & pipeline

Contacts, companies and deals with a drag-and-drop stage pipeline and value totals per stage.

Projects & tasks

Kanban board across backlog → done, priorities, due dates, project scanning sidebar.

Documents

Markdown knowledge base with rendered preview, filtering and SQLite FTS5 full-text search.

Calendar

Month grid with event chips, quick creation and upcoming view on the dashboard.

Invoices

Line items, tax rates, computed totals, status workflow (draft → sent → paid) and print/PDF rendering.

Channels

open-tag style channels and threads, agent mentions, and message-to-task conversion in one click.

Secure by default

Hardened auth

scrypt password hashing, signed session tokens, password reset flows, sessions revoked on password change.

Scoped API keys

Per-module scopes (crm:write, invoices:read …), hashed at rest, shown once, revocable.

Full audit trail

Every mutation — human or agent — lands in the audit log with actor, action, entity and timestamp.
